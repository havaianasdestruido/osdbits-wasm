Fan reconstruction for preservation. Contains no Sony firmware, BIOS dumps or extracted retail assets. Optional resource import uses files you supply.

Import a BIOS image or resource container

Optional. Selecting a PS2 boot ROM you dumped from your own console (or a bare TEXIMAGE / FNTIMAGE container) replaces the built-in procedural textures and fonts with the ones decoded from that image. Nothing is uploaded anywhere — decoding happens in this tab and the result is stored locally.
